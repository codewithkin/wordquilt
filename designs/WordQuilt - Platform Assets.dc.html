Expo generates every derived size at build time, so author each source at 1024 and let prebuild downscale — the ladder above is what those downscales must still read as, not extra files to ship. iOS icons must be fully opaque with square corners; Expo will not strip alpha for you and App Store Connect rejects it. Android adaptive layers are treated as 108dp square with only the centre 72dp guaranteed visible, and the monochrome layer must be one flat shape on transparency because its colour is discarded. Splash background is set as a colour, not an image, so it fills any aspect ratio without seams.
